# Project tracking

The organization-level delivery record is maintained in [`project-delivery-status.md`](./project-delivery-status.md).

Use that record with:

- Linear project `github.com/zed-pkg` and GitHub Project `zed-pkg-project` for the `zed-pkg` organization;
- Linear project `github.com/zed-pkg-test` and GitHub Project `zed-pkg-test-project` for the `zed-pkg-test` organization;
- Linear acceptance issue `DEN-2211` for the initial publication tranche.

The default convention is one Linear project named `github.com/<organization>` and one organization GitHub Project named `<organization>-project`. Cross-organization work links related issues rather than silently merging organization ownership.

Implementation source, exact-head CI, retained artifact evidence, and merge commits remain in GitHub. Planning, ownership, dependencies, and acceptance remain in Linear.
